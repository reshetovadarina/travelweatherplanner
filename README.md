Сучасний, легкий та повністю адаптивний вебдодаток для планування подорожей із можливістю перевірки поточної погоди в реальному часі та збереженням у персональний wishlist.

# Список можливостей

- **Пошук та перевірка погоди:** Миттєво знаходить та відображає 6 точних метеорологічних метрик (температуру, відчуття як, вологість, тиск, швидкість вітру та опис хмарності).
- **Динамічний Wishlist (Додавання та збереження):** Успішно знайдений погодний запит відкриває форму планування, дозволяючи зберегти місто в автономну стрічку карток.
- **Календар та персональні нотатки:** Додаток дозволяє обрати майбутню дату поїздки (минулі дні автоматично блокуються в календарі) та зафіксувати власні ідеї чи wishlist-нотатки.
- **Постійне автономне зберігання:** Усі додані картки надійно записуються в `localStorage` браузера та не зникають після повного оновлення сторінки.
- **Автоматичне оновлення:** Стрічка планів працює в режимі SPA (Single Page Application) — додавання нових міст або натискання кнопки «Видалити» миттєво перемальовує екран без перезавантаження сайту.
- **Індикатор завантаження:** Під час запиту до сервера кнопка пошуку переходить у стан «Завантаження...» із анімованим спінером, захищаючи форму від випадкових повторних кліків.
- **Локальна валідація та обробка помилок:** Додаток захищений від порожнього введення, коротких назв та кирилиці, а також чітко перехоплює помилку 404, якщо вказаного міста не існує на карті.

# Технологічний стек

- **HTML5** — семантична розмітка елементів та доступні теги форм.
- **CSS3** — сучасна двоколонкова сітка (CSS Grid, Flexbox), змінні (`:root`), плавні переходи (`transition`), анімації та повна адаптивність під мобільні екрани.
- **Vanilla JS (ES6+)** — чистий JavaScript без використання сторонніх фреймворків.
- **ES Modules** — модульна архітектура розділення логіки за допомогою нативних інструкцій `import/export`.
- **OpenWeatherMap API** — офіційний асинхронний ендпоінт (`/data/2.5/weather`) для отримання точних супутникових погодних даних.

# Структура проєкту

Проєкт має строгу та чисту файлову архітектуру розмежування обов'язків:

- `index.html` — єдиний HTML-файл у корені, що задає базову структуру додатку та елементів форм.
- `eslint.config.js` — конфігурація суворого інспектора ESLint для автоматичного контролю якості JS-коду.
- `.prettierrc` — правила автоматичного вирівнювання стилю коду (відступи, крапки з комою, лапки) через Prettier.
- `package.json` — паспорт проєкту для менеджера npm, що містить список встановлених інструментів та скрипти запуску.
- `.gitignore` — файл виключення, що блокує потрапляння в репозиторій системного сміття (`.DS_Store`, `.vscode/`, `node_modules/`).
- `css/style.css` — стилі оформлення Clean & Soft Travel UI, анімації, ефекти ховерів та адаптивні медіазапити.
- `js/script.js` — головна точка входу, яка координує роботу двох форм та нативно запускає завантаження даних.
- `js/api.js` — модуль асинхронних запитів до OpenWeatherMap API з нативним спливанням помилок та switch-функцією обробки HTTP-статусів.
- `js/validation.js` — модуль локальної ізольованої перевірки полів вводу (назва міста латиницею, майбутня дата в календарі).
- `js/renderer.js` — модуль рендерингу інтерфейсу (UI), відображення карток погоди, списку планів та точкового виведення помилок.
- `js/storage.js` — модуль управління пам'яттю (запис, завантаження та фільтрація масивів у `localStorage` браузера).

# Примітка про API-ключ

У файлі `js/api.js` відкрито прописано безкоштовний навчальний ключ доступу `995dd282529ced4808cb6801f4e1123c` для OpenWeatherMap API.

**Чому він лежить у репозиторії?**
Цей проєкт є повністю клієнтським додатком (Client-Side Application) без власної серверної частини (Backend). Оскільки авторизація відбувається повністю на стороні клієнта у вашому браузері, приховати ключ за допомогою серверних змінних оточення (`.env`) у даній архітектурі технічно неможливо. Даний ключ є демонстраційним, має суворі безкоштовні ліміти на кількість запитів за хвилину і не містить жодних платіжних або приватних даних розробника.
